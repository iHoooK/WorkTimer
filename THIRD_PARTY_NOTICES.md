# Сторонние компоненты

MIT WorkTimer относится к собственному коду, документации и оригинальной иконке. Сторонние компоненты сохраняют собственные авторские права и лицензии. В поставке находится папка `licenses` с полными текстами, а ниже — перечень фактически встроенных версий.

## pystray: исходники и замена

pystray © 2016–2022 Moses Palmér распространяется по LGPLv3 или более поздней версии. Полные тексты GPLv3 и LGPLv3 находятся в `licenses/pystray/`. Исходники неизменённой библиотеки находятся в `components/pystray/`, оригинальный исходный архив — в `licenses/sources/`. Источник: [pystray](https://github.com/moses-palmer/pystray).

pystray загружается из папки `components` рядом с EXE, а не из архива WorkTimer. Вы вправе изменять библиотеку и выполнять обратную разработку для отладки её изменений в соответствии с LGPL. Закройте WorkTimer, сохраните копию папки, замените `components/pystray` совместимой версией и снова запустите EXE. Пересобирать WorkTimer, приобретать лицензию или отключать проверку подписи для этого не требуется. Вызовы используют публичные `Icon`, `Menu`, `MenuItem` и обработчики меню. Если изменённая версия несовместима, восстановите папку. Полные правила определяются LGPL/GPL, а не этим пояснением.

## Python и нативные библиотеки

Python включён без изменений исходного кода; упаковка выполнена PyInstaller. `licenses/Python-Windows-LICENSE.txt` содержит лицензию Python, историю лицензирования и уведомления включённых компонентов Windows-сборки, включая условия Microsoft Distributable Code. Эти условия распространяются на соответствующий код Microsoft, а не заменяют MIT собственного кода WorkTimer.

В частности, при дальнейшем распространении кода Microsoft нельзя удалять его уведомления, заявлять поддержку продукта Microsoft без оснований, поставлять этот код для неподдерживаемых Microsoft платформ или включать его в вредоносные, вводящие в заблуждение либо незаконные программы. Получатели должны соблюдать применимые условия этого компонента.

OpenSSL, SQLite и библиотеки Pillow сохраняют собственные условия. Полные уведомления зависимостей Pillow включены в его файл лицензии. Для FreeType используется FreeType License: portions of this software are copyright © The FreeType Project (https://freetype.org). All rights reserved. Оригинальная иконка WorkTimer создана геометрическим рисунком, сторонние шрифтовые файлы не поставляются.

## Инструменты сборки

PyInstaller и Inno Setup используются при сборке; их компиляторы не включены в приложение. Исключение PyInstaller допускает распространение собранного приложения под собственной лицензией с соблюдением лицензий зависимостей. Условия используемых инструментов: [PyInstaller](https://pyinstaller.org/en/stable/license.html), [Inno Setup](https://jrsoftware.org/isinfo.php).
