    Релизы на GitHub ↗

    Перед установкой сессия сохранится на паузе, а база — в резервной копии. После обновления WorkTimer запустится снова.

    Проверка обращается к GitHub. Задачи и история остаются на компьютере. Автоматическую проверку можно отключить в настройках.

    Документы

    Справка и условия доступны без интернета. Для личного и коммерческого использования — бесплатно, по лицензии MIT. Сторонние компоненты сохраняют свои лицензии.

    Вопросы и ошибки

    Задайте вопрос в «Кодовой Артели». Для сообщения об ошибке опишите действие, ожидаемый результат и то, что произошло.

    Диагностика содержит версию, ОС, разрядность и версию Python. Задачи, история и журналы в неё не входят. Проверьте содержимое перед отправкой; поддержка не получает данные автоматически.

    Ваши данные

    Настройки, задачи и история находятся на этом компьютере. Резервную копию можно скачать в настройках. Удаление программы сохраняет историю; полное удаление данных описано в руководстве.
