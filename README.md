# WorkTimer

**Работа, отдых и стримы — в одном локальном таймере для Windows.**

Создавайте сценарии из фаз, работайте по Pomodoro, связывайте время с задачами и выводите таймер в OBS. WorkTimer работает в трее, а панель управления открывается в браузере. Аккаунт не нужен; задачи и история сохраняются на вашем компьютере.

[Скачать программу](https://github.com/iHoooK/WorkTimer/releases/latest) · [Руководство](docs/USAGE.md) · [История изменений](docs/CHANGELOG.md) · [Вопросы и обсуждения](https://t.me/codeartel)

## Скачать и запустить

**Windows 10/11 x64 · Python и Git для запуска не нужны.**

Откройте [последний релиз](https://github.com/iHoooK/WorkTimer/releases/latest) и выберите файл в разделе **Assets**:

| Вариант | Файл | Как запустить |
|---|---|---|
| Установщик | `WorkTimer-Setup-<версия>.exe` | Запустите мастер установки, затем WorkTimer через ярлык. По умолчанию устанавливается в `C:\Program Files\WorkTimer`; подтвердите запрос прав администратора Windows. |
| Без установки | `WorkTimer-Portable-<версия>.zip` | Извлеките весь архив, откройте папку `Work Timer Portable` и запустите `WorkTimer.exe`. |

Рядом лежит `SHA256SUMS`: это контрольные суммы файлов. Для обычного запуска скачивать его не нужно. Автоматические ссылки **Source code** содержат исходники для разработчиков; для запуска выбирайте EXE или Portable ZIP.

В portable-поставке сохраняйте папки `_internal`, `components` и остальные файлы рядом с EXE. Portable означает запуск без установки: история по умолчанию хранится в `%LOCALAPPDATA%\WorkTimer`, как и у установленной версии.

После первого запуска выберите сценарий или Pomodoro и нажмите старт. Для OBS откройте раздел «Оверлеи OBS» и скопируйте URL в источник «Браузер». Закрытие вкладки оставляет таймер работающим в трее; выход — через трей или настройки.

## Возможности

- Сценарии с подготовкой, работой, отдыхом и настраиваемым числом циклов.
- Pomodoro и свободный режим, пауза и продолжение сохранённой сессии.
- Задачи и группы, оценки времени, история, сводки и экспорт CSV.
- Оверлеи OBS с прозрачным фоном и выбранным цветовым акцентом.
- Трей, глобальные горячие клавиши, звук и Windows-уведомления.
- Локальная SQLite-база, резервные копии и восстановление.
- Проверка новых версий и обновление установленной программы через GitHub Releases.
- Офлайн-руководство, лицензии и диагностика в разделе «О программе».

## Обновления и данные

Новые версии проверяются раз в сутки; ручная проверка — в «О программе → Обновления». По вашему подтверждению WorkTimer скачает установщик, проверит SHA-256, сохранит резервную копию базы и перезапустится. Активная сессия восстановится на паузе. Проверку можно отключить в настройках.

Пользователям версий до `1.0.2` нужно один раз установить новый выпуск вручную. Portable обновляется распаковкой нового архива в отдельную папку.

Приложение работает без интернета; сеть нужна для проверки и скачивания обновлений и открытия внешних ссылок. Задачи и история автоматически разработчику не отправляются. [Подробнее о приватности](docs/PRIVACY.md).

Удаление программы сохраняет историю. Перед переносом данных скачайте копию в «Настройки → Данные». [Использование отдельного профиля и полное удаление](docs/USAGE.md).

## Сборка из исходников

Для сборки нужны Windows x64, Python 3.14+, Git Bash и [Inno Setup 6](https://jrsoftware.org/isdl.php). Первый запуск скачивает зависимости. В Git Bash из корня репозитория:

```bash
bash scripts/build.sh
```

Команда создаёт окружение, запускает проверки и собирает установщик и portable. Файлы для публикации и подсказки формируются автоматически:

```text
Build/
├── WorkTimer-Setup-<версия>.exe
└── Work Timer Portable/
    ├── WorkTimer.exe
    ├── _internal/
    ├── components/
    └── справка и лицензии

Release/
├── Uploads/
│   ├── WorkTimer-Setup-<версия>.exe
│   ├── WorkTimer-Portable-<версия>.zip
│   └── SHA256SUMS
├── GUIDE.html
├── GUIDE.md
└── RELEASE_NOTES.md
```

Если Python или Inno Setup находятся нестандартно:

```bash
WORKTIMER_PYTHON='C:/Path/To/python.exe' ISCC='C:/Path/To/ISCC.exe' bash scripts/build.sh
```

## Выпуск новой версии

Для первой публикации откройте [пошаговый гид](docs/GITHUB_RELEASE_GUIDE.md) или готовый `Release/GUIDE.html`. Он содержит названия кнопок GitHub, оформление репозитория, загрузку файлов и проверку результата. Текст описания подготовлен в `Release/RELEASE_NOTES.md`.

Для следующих выпусков измените `VERSION` в `app/product.py` и добавьте запись в `docs/CHANGELOG.md`. Можно собрать и загрузить файлы вручную либо отправить тег `v<версия>`: GitHub Actions подготовит черновик релиза. [Техническая инструкция](docs/RELEASE.md).
