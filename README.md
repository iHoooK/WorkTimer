# WorkTimer

WorkTimer - локальный таймер сценариев для Windows. Вместо жесткой пары "работа/отдых" приложение хранит цепочку настраиваемых фаз: подготовка, фокус, перерыв, задержка стрима, эфир или любая своя фаза.

## Возможности

- Несколько сценариев с произвольным списком фаз.
- Для каждой фазы задаются название, длительность, роль цвета, звук, уведомление, автостарт следующей фазы и заметка.
- Автопереход выключен по умолчанию и включается отдельно для нужных фаз.
- После завершения фазы остается модальное окно подтверждения следующего действия.
- Тема по умолчанию следует системной теме Windows.
- Ручной выбор `Светлая` или `Тёмная` сохраняется и блокирует системную смену, пока пользователь не переключит тему снова.
- OBS Browser Source запускается при старте приложения.
- В настройках есть OBS URL для копирования.
- Журнал событий хранится отдельно и экспортируется в CSV.
- Горячие клавиши: `Ctrl+Alt+Space` старт/пауза, `Ctrl+Alt+S` стоп.

## Локальные данные

Пользовательские файлы не создаются рядом с кодом или `.exe`.

На Windows данные лежат в:

```text
%LOCALAPPDATA%\WorkTimer\
```

Файлы:

- `settings.json` - настройки приложения и сценарии.
- `journal.json` - журнал событий таймера.

При первом запуске приложение пробует мигрировать старые данные из `data/settings.json` или `~/.focus_timer_config.json`, если новый локальный файл еще не создан.

## OBS

OBS-сервер стартует автоматически на порту `8765`.

Адрес Browser Source:

```text
http://127.0.0.1:8765/
```

Тот же адрес отображается в окне настроек, его можно скопировать кнопкой `Copy`.

## Журнал и CSV

В журнал пишутся события жизненного цикла таймера:

- `timer.started`
- `timer.paused`
- `timer.resumed`
- `timer.stopped`
- `timer.finished`

Ежесекундные `tick`-события не пишутся, чтобы файл не разрастался без пользы. CSV экспорт доступен из настроек кнопкой `CSV`.

## Запуск из исходников

```powershell
pip install -r requirements.txt
python main.py
```

## Структура

```text
core/            бизнес-логика: таймер, сценарии, настройки, журнал
infrastructure/  файлы, OBS, звук, уведомления, трей, хоткеи
ui/              окна и компоненты CustomTkinter
data/            пример настроек без пользовательского состояния
```
