# WorkTimer

Локальный таймер сценариев, задач и тайм-трекинга для Windows. Приложение запускает localhost-панель и работает в трее; облака, аккаунты и внешний сервер не нужны.

## Запуск

Нужен установленный Python 3.14 (или более новый совместимый Python 3).

### Первый запуск или после обновления Python

Откройте PowerShell в папке проекта и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### Обычный запуск

```powershell
.\.venv\Scripts\python.exe main.py
```

При желании можно сначала активировать окружение, а затем запускать приложение короткой командой:

```powershell
.\.venv\Scripts\Activate.ps1
python main.py
```

Если PowerShell запрещает запуск `Activate.ps1`, используйте вариант без активации выше — он работает всегда.

Панель откроется по адресу `http://127.0.0.1:8765/`. Закрытие браузера не останавливает таймер.

Чтобы завершить приложение, щёлкните правой кнопкой по его значку в системном трее и выберите выход.

## OBS

В разделе **Stream / OBS** доступны два Browser Source URL:

- `/overlay/minimal` — только цифры таймера и тонкая полоса, прозрачный фон;
- `/overlay/scene` — текущая и следующая фазы для starting/break-сцен.

Оба оверлея получают состояние с того же localhost-сервера. Для акцента можно добавить безопасный параметр, например `?accent=%2322c7ff`.

## Данные

SQLite-база и мигрированные старые данные хранятся в `%LOCALAPPDATA%\WorkTimer\`. При первом запуске сценарии импортируются из legacy JSON, а исходный журнал сохраняется отдельно в SQLite без изменения оригинальных событий.

## Горячие клавиши

- `Ctrl+Alt+Space` — старт / пауза;
- `Ctrl+Alt+Right` — следующая фаза;
- `Ctrl+Alt+R` — начать сценарий сначала.
