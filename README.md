# Work Timer 🎯

Минималистичный таймер работы/отдыха для Windows с уведомлениями и системным треем.

## Функции

- ⏱ Таймер работы и отдыха с настраиваемыми интервалами
- 🔔 Звуковой сигнал + всплывающее уведомление Windows при окончании
- 👤 3 профиля: Работа (60/10), Учёба (50/10), Спорт (45/15)
- 🔇 Режим "Не беспокоить" — отключает уведомления, таймер продолжает работать
- 🗂 Сворачивание в системный трей (правой кнопкой на иконке — меню)
- ⌨ Горячие клавиши: `Ctrl+Alt+Space` (старт/пауза), `Ctrl+Alt+S` (стоп)

## Установка и запуск

### Требования
- Windows 10/11
- Python 3.9 или выше

### Шаг 1 — Установить Python
Скачайте с https://www.python.org/downloads/  
**Важно:** при установке поставьте галочку **"Add Python to PATH"**

### Шаг 2 — Запустить сборку

**Через bash (Git Bash, WSL и т.п.):**
```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

**Через PowerShell напрямую:**
```powershell
.\build.ps1
```

**Двойным кликом:** правой кнопкой на `build.ps1` → *"Выполнить с помощью PowerShell"*

Скрипт сам установит все зависимости и соберёт EXE.

### Шаг 3 — Готово
Файл `dist\WorkTimer.exe` — это ваше приложение.  
Можно скопировать его куда угодно и запускать без Python.

## Структура проекта

```

  main.py          — точка входа приложения
  requirements.txt — список зависимостей

  infrastructure/  — файлы, звук, трей, хоткеи
  ui/              — интерфейс
```

## Ручной запуск (без сборки EXE)

```bash
pip install -r requirements.txt
python main.py
```

## Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Ctrl+Alt+Space` | Старт / Пауза |
| `Ctrl+Alt+S` | Стоп и сброс |

Работают глобально — даже когда окно свёрнуто в трей.

## Настройка профилей

1. Выберите профиль кнопкой вверху
2. Введите нужное время в полях "Работа" и "Отдых"
3. Нажмите "Сохранить профиль"

Настройки сохраняются в файл `data/settings.json` рядом с приложением. При первом запуске приложение может перенести данные из старого файла `~/.focus_timer_config.json`, если новый файл ещё не создан.
