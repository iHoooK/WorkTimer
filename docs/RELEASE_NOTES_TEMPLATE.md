# WorkTimer {{VERSION}}

Локальный таймер для работы и стримов на Windows: сценарии, Pomodoro, задачи, история времени и оверлеи OBS. Работает в трее, управляется через браузер и сохраняет данные на вашем компьютере.

## Какой файл скачать

| Файл | Для кого | Что делать |
|---|---|---|
| `WorkTimer-Setup-{{VERSION}}.exe` | Хочу обычную установку с ярлыками | Запустите установщик и следуйте мастеру. Стандартная папка — `C:\Program Files\WorkTimer`. Подтвердите запрос прав администратора Windows. |
| `WorkTimer-Portable-{{VERSION}}.zip` | Хочу запускать без установки | Распакуйте весь архив и запустите `Work Timer Portable/WorkTimer.exe`. |
| `SHA256SUMS` | Хочу проверить целостность загрузки | Сравните SHA-256 скачанного файла с указанным значением. Для обычного запуска скачивать этот файл не нужно. |

**Требования:** Windows 10/11 x64 и современный браузер. Python, Git и аккаунт GitHub для запуска не нужны.

В portable-поставке не переносите EXE отдельно: папки `_internal`, `components`, справка и лицензии должны оставаться рядом. Не запускайте приложение изнутри ZIP. Автоматические архивы **Source code** содержат исходники, а не готовую программу.

## Первый запуск

- Запустите WorkTimer: панель откроется в браузере, значок появится в трее.
- Выберите сценарий, Pomodoro или свободный режим и нажмите старт.
- Для стрима скопируйте URL из раздела «Оверлеи OBS» в источник «Браузер» в OBS.
- Закрытие вкладки не завершает таймер. Для выхода используйте трей или настройки.

## Обновления и сохранение данных

Проверка новой версии доступна в **«О программе → Обновления»**. Установленная версия скачивает и проверяет установщик, делает резервную копию базы и перезапускается после вашего подтверждения. Активная сессия сохраняется на паузе. При обновлении Windows запросит права администратора. Если отменить запрос, таймер продолжит работать. Автоматическую проверку раз в сутки можно отключить в настройках.

**При переходе с версии ниже 1.0.2 один раз установите новый выпуск вручную поверх прежней программы.** История и настройки сохранятся. Перед обновлением закройте WorkTimer через трей.

Portable обновляется распаковкой нового архива в отдельную папку. Данные обеих поставок по умолчанию находятся в `%LOCALAPPDATA%\WorkTimer`. Перед переносом компьютера сохраните копию в «Настройки → Данные».
