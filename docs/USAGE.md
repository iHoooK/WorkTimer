# Руководство WorkTimer

## Запуск и выход

Запустите `WorkTimer.exe` в portable-папке или установите программу через `WorkTimer-Setup-{{VERSION}}.exe`. Для запуска нужны Windows 10/11 x64 и современный браузер; Python отдельно не нужен. При переносе portable копируйте всю папку, включая `_internal`, `components`, документы и лицензии.

В установщике можно выбрать папку программы и ярлык на рабочем столе. Права администратора по умолчанию не требуются. Запускайте установленную программу через меню «Пуск → WorkTimer». Для обновления завершите WorkTimer и установите новую версию в ту же папку; пользовательская база сохраняется, а перед изменением её схемы создаётся копия.

Панель открывается на `http://127.0.0.1:8765/`. Закрытие вкладки оставляет таймер в трее. Выйти можно через меню трея или «Настройки → Выйти из WorkTimer». Второй запуск открывает уже работающий экземпляр.

Горячие клавиши: **Ctrl+Alt+Space** — старт/пауза, **Ctrl+Alt+→** — следующая фаза, **Ctrl+Alt+R** — начать сначала. Звук, уведомления и автоматический переход настраиваются в панели.

## Рабочие циклы без сброса

В конечном сценарии выберите одну фазу, по которой считаются рабочие циклы. Счётчик увеличивается при её запуске. Кнопка **«+ Рабочий цикл»** меняет, например, `2 из 3` на `2 из 4`, сохраняя текущую фазу, прошедшее время и паузу. Такой же результат даёт изменение общего числа в редакторе и сохранение сценария.

Сохранение, выбор и запуск — отдельные действия. Правки длительности, заметки и уведомлений текущей фазы действуют при её следующем запуске; текущее время продолжает считаться по первоначальным параметрам. Для удаления текущей фазы завершите сессию. Общее число циклов нельзя уменьшить ниже уже начатого количества. «Повторить фазу» не увеличивает счётчик; «Начать сначала» начинает новую сессию.

Бесконечный сценарий отключает маркеры циклов. Pomodoro использует собственный сценарий и не перезаписывает пользовательский сценарий с похожим названием. Свободный режим считает время вверх до завершения сессии.

## Данные и восстановление

По умолчанию и portable, и установленная версия используют `%LOCALAPPDATA%\WorkTimer\`:

- `worktimer.db` — сценарии, задачи, отрезки времени, сессии и настройки;
- `worktimer.log` — журнал с ротацией;
- `backups/` — копии перед миграцией/импортом и ручные экспорты.

Исходные legacy JSON не изменяются. История хранит снимки названий и типов фаз; редактирование сценария не переписывает старые отрезки. Корректировка времени сохраняет прежнее значение в журнале изменений.

Активный отрезок сохраняется примерно раз в секунду и при паузе/действиях. После аварийного завершения или штатного выхода он восстанавливается **на паузе** по последней сохранённой точке. Время, пока программа была выключена, не учитывается; при аварии возможна потеря последних секунд до контрольной точки. При обычном завершении время сохраняется непосредственно перед выходом.

«Настройки → Данные» позволяет скачать SQLite-копию и восстановить её после завершения сессии. Восстановление проверяет целостность, версию и связи; перед заменой делает копию текущей базы. Удаление программы через Windows сохраняет пользовательскую историю.

Для отдельного профиля: `WorkTimer.exe --data-dir "D:\WorkTimerData"`. Другому одновременно работающему профилю нужен собственный `--port`; глобальные горячие клавиши общие для Windows.

## История и задачи

Задача необязательна. Её выбор применяется к следующим отрезкам; уже запущенный отрезок остаётся у прежней задачи. Группы поддерживают один уровень подгрупп. Есть поиск по названию/тегам, статусы, архив и план/факт.

История, сводки и CSV используют одни фильтры по датам, задаче, группе, сценарию и типу фазы. По умолчанию показаны последние 14 календарных дней, включая пустые дни. Работа включает типы `work/custom` и свободный режим; отдых и подготовка считаются отдельно. История загружается страницами по 50 отрезков; CSV выгружает весь выбранный период. Последние сессии показаны отдельно с явной пометкой «все периоды».

## OBS

В разделе «Оверлеи OBS» скопируйте URL в источник **«Браузер»**:

| Оверлей | Размер источника | Содержание |
|---|---|---|
| `/overlay/minimal` | 480 × 116 | Время и полоса прогресса |
| `/overlay/scene` | 480 × 200 | Время, текущая и следующая фазы |
| `/overlay/progress` | 300 × 100 | Рабочие циклы; без лимита — соответствующая подпись |

Фон прозрачный. Акцент берётся из настроек либо безопасного параметра `?accent=%2322c7ff`. Источники восстанавливают связь после перезапуска. Превью создаются только при открытии раздела. Для нестандартного порта копируйте URL именно из текущей панели.

## Обновления программы

WorkTimer проверяет последний стабильный релиз GitHub раз в сутки и показывает уведомление при появлении новой версии. В «Настройки → Обновления» можно отключить автоматическую проверку. Таймер работает без интернета; ошибка проверки не останавливает программу.

В «О программе → Обновления» нажмите «Проверить обновления», затем «Обновить до …» и подтвердите установку. WorkTimer скачает установщик, проверит размер и SHA-256, сохранит сессию на паузе и резервную копию базы в `backups`. Установщик дождётся завершения программы, заменит файлы в прежнем каталоге и запустит WorkTimer с прежними профилем и портом. Время установки не включается в рабочую сессию. Не запускайте другие профили WorkTimer во время установки; если они уже работают, завершите их перед обновлением.

Обновление через кнопку доступно версии, установленной Windows-установщиком для текущего пользователя. Portable-версия показывает обновления и ссылку на релизы: скачайте новый ZIP и распакуйте в новую папку. Данные находятся отдельно от программы и сохраняются. Запуск из исходников обновляется разработчиком.

Если установщик не удалось скачать или проверка файла не пройдена, WorkTimer продолжит работать: повторите попытку позже. Ошибки установки показываются самим установщиком; если после ошибки программа не открылась, запустите её через ярлык. Резервные копии и журнал установки находятся в каталоге данных. Новые релизы появятся после публикации автором на GitHub.

Версии, выпущенные до 1.0.2, не умеют обновляться автоматически: установите 1.0.2 или новее вручную один раз.

## Частые вопросы

- Панель не открывается: убедитесь, что WorkTimer запущен, затем выберите «Открыть панель» в трее. Закройте старую вкладку после изменения порта.
- Порт 8765 занят: завершите другой экземпляр или запустите `WorkTimer.exe --port 8766`. Для OBS заново скопируйте адреса из этой панели.
- После перезапуска таймер стоит на паузе: это восстановленная сессия; продолжите её кнопкой старта.
- Не работают горячие клавиши: их может занимать другое приложение; проверьте `worktimer.log`. Рабочий стол администратора и некоторые системные окна ограничивают взаимодействие.
- Нет уведомлений: проверьте настройку WorkTimer и режим уведомлений Windows.
- Windows показывает неизвестного издателя: текущий выпуск не подписан сертификатом. Загружайте его из источника автора; обходить предупреждения автоматически программа не пытается.
- Сон и выключение компьютера: восстановление идёт по сохранённой точке; не рассчитывайте на уведомления при спящем или выключенном компьютере. Это инструмент организации работы, без обещания юридически достоверного учёта времени.

## Удаление

Завершите приложение через трей, затем удалите WorkTimer в «Установленных приложениях» Windows. История сохраняется. Для полного удаления служебных данных удалите `%LOCALAPPDATA%\WorkTimer` (либо свой каталог `--data-dir`) после выхода. Отдельно удалите скачанные CSV, резервные копии и старые legacy JSON, если они больше не нужны.
