# Приватность WorkTimer

WorkTimer работает локально, без аккаунтов, рекламы и телеметрии. Задачи, сценарии и история времени не отправляются разработчику автоматически.

## Какие данные сохраняются

- Названия, описания и теги задач, группы, оценки времени и статусы.
- Сценарии, названия и заметки фаз, длительности и настройки.
- Сессии, отрезки времени, исправления истории и настройки программы.
- Технический журнал запуска, ошибок и работы интеграций. Ошибки могут содержать пути к файлам и другие сведения о компьютере.
- Резервные копии базы и выгруженные пользователем CSV.

По умолчанию служебные данные находятся в `%LOCALAPPDATA%\WorkTimer`: `worktimer.db`, `worktimer.log` и его архивы, папка `backups`. Параметр `--data-dir` меняет каталог. База и копии не зашифрованы WorkTimer: доступ определяется правами Windows. Не храните здесь пароли и секреты.

## Локальный обмен и внешние сайты

Панель в браузере и оверлеи OBS обращаются к серверу на `127.0.0.1` (по умолчанию порт 8765). Это обмен внутри компьютера, а не отправка разработчику. Приложение не публикует сервер в локальной сети. По умолчанию оно проверяет новые версии на GitHub раз в сутки. Автоматическую проверку можно отключить в настройках; ручная доступна в разделе «О программе».

Кнопки сайта автора, соцсетей, поддержки и донатов открывают внешние сайты только по вашему нажатию. На них действуют правила соответствующих сервисов. WorkTimer не получает платёжные данные. Браузер, расширения, OBS и Windows могут обрабатывать данные по собственным правилам. Названия фаз, видимые в OBS, могут попасть в запись или трансляцию.

Глобальные горячие клавиши обрабатываются локально для управления таймером. WorkTimer не сохраняет набранный вами текст. Кнопка диагностики копирует только версию программы, ОС, разрядность и версию Python; содержимое задач, базы, пути профиля и журналы в неё не включаются.

При использовании OneDrive, сетевых или синхронизируемых папок данные может передавать их провайдер независимо от WorkTimer. Во время разработки и сборки интернет используется для получения зависимостей.

## Удаление и обращения

Удаление программы через Windows сохраняет вашу историю. Для полного удаления данных сначала завершите WorkTimer через трей, затем удалите каталог `%LOCALAPPDATA%\WorkTimer` либо свой каталог `--data-dir`. Отдельно удалите скачанные копии базы, CSV и старые файлы, которые вы сохранили вне этого каталога.

Вы сами выбираете, какие сведения отправить при обращении за помощью. Проверьте журнал перед отправкой; не прикладывайте базу с задачами без необходимости. Сообщения в [Кодовой Артели](https://t.me/codeartel) обрабатываются Telegram и получателями; не публикуйте личные сведения в открытом обсуждении.

## Проверка и установка обновлений

Проверка обращается к API GitHub за последним стабильным релизом `iHoooK/WorkTimer`; GitHub получает IP-адрес и технический заголовок с версией WorkTimer. Задачи, история, настройки, имя пользователя и содержимое базы не отправляются. Учётная запись GitHub и токен не нужны.

Установщик скачивается только после вашего подтверждения, по HTTPS с GitHub и его хранилища релизов. Перед запуском WorkTimer проверяет размер и SHA-256 файла, делает резервную копию базы и сохраняет сессию. Скачанный установщик и журнал установки находятся в подпапке `updates` каталога данных; их можно удалить после успешного обновления и завершения установщика. SHA-256 проверяет целостность относительно опубликованного релиза; это не подпись издателя.
