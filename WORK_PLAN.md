# WorkTimer — план полной переработки

Формат: `✅` — сделано, `[ ]` — не сделано.

Сводка: WorkTimer становится локальным инструментом сценариев, задач и тайм-трекинга. Python-процесс работает в трее и запускает web-панель на `localhost`; настройки больше не живут в отдельном desktop-окне. Для OBS предусмотрены минимальный и информативный оверлеи.

Не входит в этот план: аккаунты, облачная синхронизация, мобильное приложение, блокировка сторонних приложений, совместная работа и подписочная модель.

Правило сопровождения: после реализации каждого пункта менять статус, обновлять сводку фазы и указывать затронутые файлы, проверки и открытые риски. Старый CustomTkinter UI нельзя удалять, пока web-панель не запускается и не управляет таймером.

Текущая отправная точка: исходный проект на Python с `CustomTkinter`, JSON-хранилищем, произвольными фазами, треем, хоткеями, уведомлениями и встроенным OBS HTTP-сервером. Артефакты старых сборок и сломанные virtualenv удалены в фазе 0.

## Технические решения

| Решение | Выбор | Причина |
|---|---|---|
| Интерфейс | Локальная web-панель без Node-сборки | Сценарии, задачи, графики и настройки удобнее в браузере; запуск остаётся простым. |
| Runtime | Python + localhost API + статические HTML/CSS/JS | Один локальный процесс без деплоя и фронтенд-сборки. |
| Хранилище | SQLite | Надёжная история задач, сессий и аналитики вместо разрастающихся JSON. |
| Доступ | Только `127.0.0.1` | Панель и OBS не доступны из локальной сети. |
| Обновления | SSE с fallback-поллингом | Состояние таймера синхронно в панели и OBS. |
| Desktop-слой | Трей, hotkeys, уведомления и звук | Сохраняются важные интеграции Windows без окна настроек. |
| OBS | Два независимых URL: `minimal` и `scene` | Неперегруженный таймер в рабочей сцене и контекст в starting/break. |
