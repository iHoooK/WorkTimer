# WorkTimer Design System

Матовая цифровая мастерская: тёмные сине-графитовые поверхности, голубой акцент и крупный моноширинный таймер. Визуальная основа сохранена после аудита; главные изменения — ясные действия, полное состояние и доступные формы.

| CSS token | Цвет | Назначение |
|---|---|---|
| `--bg` | `#07111c` | Фон |
| `--surface` | `#0c1a29` | Панели и навигация |
| `--raised` | `#102337` | Контролы и активная строка |
| `--line` | `#294259` | Границы |
| `--text` | `#eaf2f8` | Основной текст |
| `--muted` | `#a0b3c4` | Вторичный текст |
| `--accent`, `--work` | `#22c7ff` | Основное действие и работа |
| `--rest` | `#56d6a0` | Отдых |
| `--prep` | `#9b8cff` | Подготовка |
| `--danger` | `#ff9da3` | Архив и ошибки |

Шрифты системные, без сетевой загрузки: Segoe UI / system-ui; таймер — Cascadia Mono / Consolas. Основной текст 15 px, подписи 13 px. Цифры адаптируются к ширине и используют tabular figures.

Навигация 216 px на широком экране. До 1100 px таймер и контекст складываются в одну колонку; до 760 px навигация становится верхней сеткой. Поля используют minmax(0, 1fr), действия переносятся целыми группами. Проверенные ширины: 360, 390, 768, 1024, 1440 px.

Контролы имеют радиус 8 px, поверхности — 10 px. Кликабельные цели обычно не меньше 44 px. Focus-visible — голубая рамка 2 px с отступом 4 px. Основное действие залито голубым; остальные имеют спокойную границу. Фазы редактора показывают подписанные поля; звук, уведомления и заметка скрыты в details. Порядок меняется кнопками, доступными с клавиатуры.

Статус таймера объявляется отдельно от секунд. Навигация использует aria-current, progressbar — численные значения. Диалоги нативные: Escape, фокус и возврат к инициатору. Цвет всегда сопровождается текстом. Панель и OBS учитывают prefers-reduced-motion. Полная сертификация WCAG/NVDA не заявляется.

Сохранить, выбрать и запустить — отдельные действия. У редактора есть dirty-state и сохраняемый черновик. Пустые состояния объясняют следующий шаг. Оверлеи имеют по одному ленивому превью точного размера; после ухода из раздела iframe удаляются.
